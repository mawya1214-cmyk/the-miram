# THE MIRAM — Official Film Website

A professional, responsive, bilingual (English/Arabic) static website for **THE MIRAM**.

## Film

**THE MIRAM** is a Sudanese AI-assisted 3D animated short film about resilience, education, hope, and the human cost of war.

- **Runtime:** 7 minutes 15 seconds
- **Language:** English
- **Format:** 16:9, 4K
- **Year:** 2026
- **Director & Writer:** Muawia Ismail

## Files

- `index.html` — website structure and content
- `style.css` — cinematic responsive design
- `script.js` — Arabic/English language switch, mobile menu and Google Drive trailer
- `assets/` — poster, production stills and press materials

## Official Trailer

The official trailer is hosted on Google Drive and embedded in the website using the Google Drive preview player.

If the trailer does not play, make sure the Google Drive file sharing setting is:

**General access → Anyone with the link → Viewer**

## GitHub Pages

Upload the project files to a GitHub repository and enable **Settings → Pages → Deploy from a branch → main → /(root)**.

GitHub Pages publishes static HTML, CSS and JavaScript directly from the repository.
