# THE MIRAM — Official Film Website

A cinematic bilingual static website for **THE MIRAM — The Light That No War Can Dim**, a Sudanese AI-assisted 3D animated short film written and directed by **Muawia Ismail Ibrahim**.

- Runtime: 7 minutes 15 seconds
- Language: English
- Format: 16:9, 4K
- Year: 2026
- Trailer: Google Drive
- Privacy Policy: `privacy.html`

## Upload structure

Keep these files at the repository root:

```text
index.html
privacy.html
style.css
script.js
README.md
.nojekyll
assets/
```

Put the real PNG assets inside `assets/` using these filenames:

```text
poster.png
director.png
still-01.png
still-02.png
still-03.png
still-04.png
still-05.png
still-06.png
THE_MIRAM_Press_Kit.pdf
THE_MIRAM_Director_Statement.pdf
THE_MIRAM_Credits.pdf
```

If `director.png` is not uploaded yet, the site shows a designed fallback block instead of a broken image.

## GitHub Pages

Enable **Settings → Pages → Deploy from a branch → main → /(root)**.
